🌿 Ramas

Durante el proyecto utilizaremos diferentes ramas para practicar el flujo de trabajo con Git.

Ejemplo:

git branch desarrollo
git checkout desarrollo


También podemos crear y cambiar a una rama directamente:

git switch -c desarrollo


Una vez realizados los cambios:

git add .
git commit -m "Agregando cambios"
git push origin desarrollo

💻 Comandos básicos de Git
Inicializar un repositorio
git init

Ver el estado del repositorio
git status

Agregar archivos
git add .

Crear un commit
git commit -m "Primer commit"

Ver los commits
git log

Crear una rama
git branch nombre-rama

Cambiar de rama
git switch nombre-rama

Fusionar una rama
git merge nombre-rama

Subir cambios a GitHub
git push

Descargar cambios
git pull
